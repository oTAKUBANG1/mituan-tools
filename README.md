# 米团小工具

一个 HTML 文件，三个日常小工具：**番茄钟 / 待办 / 记账**。

双击打开就能用。不联网、不装任何东西、数据只存在你自己的浏览器里。

## 三个工具

| | |
|---|---|
| 🍅 **番茄钟** | 专注 25 / 短休 5 / 长休 15，圆环进度，统计今天完成几个、累计专注多久 |
| ✅ **待办** | 增删、勾选、筛选。可以给一条待办设截止时间，到点弹系统通知 |
| 💰 **记账** | 记收支，自动算当月支出/收入/结余；分类饼图 + 每日支出条形 |

## 记账：能导入支付宝 / 微信账单

点「导入账单」，选两个平台导出的 CSV 就行。

- **支付宝**（`alipay_record_*.csv`）：UTF-8 和 GBK 都能读，自动探测
- **微信**（`微信支付账单明细*.csv`）：UTF-8 with BOM

处理了几个容易踩的地方：

1. **表头不在第一行**：两个平台导出的文件前面都有账号、日期范围的说明行，靠关键词找表头，不写死行号
2. **编码探测**：先按 UTF-8 解，出现替换字符就换 GBK
3. **金额格式**：`¥35.00`、`1,280.00` 都能解析
4. **去重**：按交易单号记，重复导入会跳过
5. **「不计收支」跳过**：支付宝里转账这类不算收支

分类会自动猜（美团→吃饭、滴滴→交通、盒马→购物、工资→工资），猜不中归「其他」，之后可以手动改。

## 备份

所有数据都在浏览器的 `localStorage` 里，清缓存 / 换浏览器就没了。

右上角有 **「备份」**：把三个工具的数据打包成一个 JSON 下载。
**「恢复」**：读回来，确认后覆盖当前数据。

建议隔一段时间点一次，尤其记了几个月账之后。

## 已知限制

- **待办提醒只在页面开着时有效**。关掉浏览器就不会弹了 —— 浏览器通知本来就是这个机制，
  要做成关掉也能提醒，得做成 PWA 或者桌面程序。
- 数据不跨浏览器：Chrome 里记的账，Edge 里看不到。想带过去用备份。
